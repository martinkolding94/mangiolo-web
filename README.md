# mangiolo-web

Den statiske hjemmeside på [mangiolo.com](https://mangiolo.com): forside, juridiske sider og landingsside for delte opskrifter. Ren HTML/CSS, ingen cookies eller tracking. Hostes på GitHub Pages fra `main`.

- `/` forside · `/privacy` · `/terms` · `/guidelines`
- `/recipe/{id}` findes ikke som fil – GitHub Pages serverer `404.html`, som viser opskriftsteksten, når stien starter med `/recipe`.
- Teksterne kommer fra Notion (Mangiolo → MG-7) og rettes der først.
- Skrifter: Newsreader og Instrument Sans (SIL OFL 1.1, licenser i `assets/fonts/`), hostet her, så der ikke kaldes til Google.
